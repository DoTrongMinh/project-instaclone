# project-instaclone
Tạo đăng nhập, đăng kí và chỉnh sửa tài khoản đã đăng kí bằng Devise, Thêm Profiles vào User. Thêm phần Comment, Like và Dislike ở bài đăng, Thêm thanh tìm kiếm theo tên người dùng. Cuối cùng là thêm phần vai trò Quản trị viên và Bảng điều khiển của Quản trị viên và Bảng phân tích cho quản trị viên.
